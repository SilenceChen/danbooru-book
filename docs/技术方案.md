# Danbooru Tag 管理系统 - 技术方案

## 技术栈

| 层级 | 技术选型 |
|------|---------|
| 后端 | Python 3.11 + FastAPI |
| 数据库 | SQLite（轻量）→ 可迁移至 PostgreSQL |
| 爬虫 | httpx + APScheduler（定时任务） |
| 翻译/分类 | Gemini API（用户自有 API Key） |
| 前端 | React 19 + Vite + TypeScript |
| UI 组件库 | Ant Design 5 |
| 状态管理 | Zustand |
| 数据请求 | TanStack Query (React Query) |
| 包管理 | uv（Python） |

## 数据库设计

```sql
-- Tag 主表
CREATE TABLE tags (
    id INTEGER PRIMARY KEY,
    name TEXT UNIQUE NOT NULL,          -- 原始英文 tag
    name_zh TEXT,                       -- 中文名
    description_zh TEXT,               -- 中文解释
    danbooru_category INTEGER,         -- Danbooru 原始分类(0=General,1=Artist,3=Copyright,4=Character,5=Meta)
    post_count INTEGER DEFAULT 0,      -- 使用次数
    representative_image_url TEXT,     -- 代表图片
    crawled_at TIMESTAMP,
    translated_at TIMESTAMP,
    updated_at TIMESTAMP
);

-- 分类表
CREATE TABLE categories (
    id INTEGER PRIMARY KEY,
    name TEXT UNIQUE NOT NULL,         -- 分类名（中文）
    sort_order INTEGER
);

-- Tag ↔ 分类 多对多关联表
-- 一个 tag 可属于多个分类（如 "red hair" 同属「头发」和「颜色」）
CREATE TABLE tag_categories (
    tag_id INTEGER NOT NULL REFERENCES tags(id),
    category_id INTEGER NOT NULL REFERENCES categories(id),
    is_primary BOOLEAN DEFAULT 0,      -- 是否为主分类（用于默认展示）
    source TEXT DEFAULT 'llm',         -- 来源：llm / rule / manual
    PRIMARY KEY (tag_id, category_id)
);

-- 用户组合模板
CREATE TABLE compositions (
    id INTEGER PRIMARY KEY,
    name TEXT,
    positive_tags TEXT,               -- JSON 数组 [{id, weight}]
    negative_tags TEXT,               -- JSON 数组 [{id, weight}]
    created_at TIMESTAMP
);
```

## 爬取策略

| 类型 | 策略 |
|------|------|
| 初次全量 | 按使用次数从高到低爬取 Top 50000 tags |
| 增量更新 | 每天凌晨爬取新增/变更 tags（按 updated_at 过滤） |
| 图片爬取 | 每个 tag 取 post_count 最高的1张图作为代表图 |
| 频率控制 | 1 req/s（无账号），避免封禁 |

---

## 翻译批处理策略

| 项目 | 说明 |
|------|------|
| 批量大小 | 每批 50 个 tag，单次 LLM 调用 |
| 模型选择 | Gemini Flash（快速低成本） |
| 翻译优先级 | post_count 高的优先翻译 |
| 人工校正 | 提供后台界面手动修改翻译 |
| 同步输出分类 | 翻译时一并让 Gemini 返回建议分类列表，避免二次调用 |

## API 接口规划

### Tag 接口
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/tags` | 搜索/列出 tags（支持 q、category、page 参数） |
| GET | `/api/tags/{id}` | 获取单个 tag 详情 |
| PATCH | `/api/tags/{id}` | 手动修改翻译/分类 |

### 分类接口
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/categories` | 获取所有分类 |
| GET | `/api/categories/{id}/tags` | 获取某分类下的所有 tags |

### 组合接口
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/compositions` | 获取保存的组合模板 |
| POST | `/api/compositions` | 保存新组合 |
| DELETE | `/api/compositions/{id}` | 删除组合 |

### 任务接口
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/tasks/crawl` | 手动触发爬取 |
| POST | `/api/tasks/translate` | 手动触发批量翻译 |
| GET | `/api/tasks/status` | 查看任务状态 |
