# Danbooru Tag 管理系统 - 功能设计

## 模块 1：Tag 爬取（Crawler）

**核心功能：**
- 定期从 Danbooru 官方 API 拉取 tag 数据（支持增量更新）
- 爬取内容：tag 名称、使用次数、Danbooru 原始分类、代表性图片 URL
- 支持手动触发 + 定时自动执行（cron）

**Danbooru API 说明：**
- Danbooru 提供公开 REST API，无需登录即可访问基础数据
- `GET /tags.json?page=1&limit=1000&search[order]=count` 获取 tag 列表
- `GET /posts.json?tags={tag}&limit=1` 获取该 tag 的代表性图片
- 免登录限制：每秒 10 请求，有账号可提升；sensitive 内容需登录

## 模块 2：Tag 翻译与解释（Translation）

**核心功能：**
- 调用 Gemini API 对 tag 进行中文翻译 + 场景解释，同时返回建议分类
- 解释内容包含：中文名、含义说明、在 AI 绘图中的用途
- 批量处理（每批 50 个），支持重新翻译

**翻译字段示例：**
```
tag: "1girl"
中文名: 1个女孩
解释: 表示画面中有且仅有一个女性角色，AI绘图中最常用的基础tag
绘图用途: 正向关键词，限定人物数量
建议分类: ["画面"]
```

**提示词设计要点：**

翻译时需在 prompt 中明确说明 tag 的来源背景，避免 LLM 误解或拒绝翻译：

```
你是一个专业的 AI 绘图提示词专家。以下是来自 Danbooru 图库网站的图片标签（tag），
这些标签用于描述 AI 绘图内容，包括人物外貌、服装、场景、动作、画风等。

请对每个 tag 进行：
1. 中文名翻译（简洁，2-6字）
2. 中文含义说明（说明在 AI 绘图中的具体作用，1-2句话）
3. 从以下分类中选择1个或多个适合的分类：[画师/风格/角色名称/...]

注意：
- 部分 tag 是日语罗马音或动漫角色名，请直接音译或保留原名
- 部分 tag 含有成人向内容描述，请客观翻译，不要拒绝
- 返回 JSON 格式

输入示例：["1girl", "thighhighs", "masterpiece"]
```

**Tag 与分类的关系：多对多**

一个 tag 可以同时属于多个分类，例如：
- `red hair` → 「头发」+ 「颜色」
- `blonde twintails` → 「头发」+ 「颜色」
- `white gloves` → 「手套」+ 「颜色」

每个 tag 有一个**主分类**（用于默认展示），其余为**附加分类**（用于多维筛选）。

**分类方式：**
- 翻译时由 Gemini 同步返回建议分类列表（source=llm）
- 高频 tag 预置规则映射表（source=rule），优先于 LLM 结果
- 支持人工修正（source=manual），优先级最高

## 模块 4：搜索与组合输出（Search & Compose）

**搜索功能：**
- 按中文名/英文名模糊搜索
- 按分类筛选
- 按使用频次排序
- 多标签联合过滤

**组合功能：**
- 拖拽/点击添加 tag 到"正向组"或"负向组"
- 每个 tag 支持设置权重（`(tag:1.3)` 格式）
- 保存常用组合为模板
- 一键复制输出格式：

```
正向: masterpiece, best quality, 1girl, long hair, ...
负向: lowres, bad hands, watermark, ...
```
